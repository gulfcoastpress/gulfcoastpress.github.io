Archive Old Gmail Promotions (free starter workflow)
=====================================================

WHAT IT DOES
Every night at 22:00, inbox mail in the Promotions tab older than 7 days that is not starred or important is archived. It never deletes. No AI, no cost.

NEEDS
Gmail. n8n Cloud or self-hosted, n8n 1.x (import-tested on 1.123.91).

SET UP (about 3 min)
1. In n8n: Workflows > Import from file > pick archive-old-gmail-promotions.json.
2. Read the yellow note on the canvas, then fill the Config node if there is one.
3. Open each node with a red warning and pick your own credential. Nothing is hard-coded.
4. Test with your own email or a test form post first. Then activate.
