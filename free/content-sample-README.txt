RSS to LinkedIn Draft (free starter workflow)
==============================================

WHAT IT DOES
Each new post in your blog's RSS feed becomes one LinkedIn draft in a Google Sheet queue, written only from that post's facts. Nothing is posted for you.

NEEDS
RSS · OpenAI · Sheets. n8n Cloud or self-hosted, n8n 1.x (import-tested on 1.123.91).

SET UP (about 10 min)
1. In n8n: Workflows > Import from file > pick content-sample.json.
2. Read the yellow note on the canvas, then fill the Config node if there is one.
3. Open each node with a red warning and pick your own credential. Nothing is hard-coded.
4. Test with your own email or a test form post first. Then activate.
