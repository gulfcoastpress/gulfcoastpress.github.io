Multi-Source Lead Capture (lite) (free starter workflow)
=========================================================

WHAT IT DOES
One webhook takes Typeform, Tally, Jotform or any JSON form, normalises name, email, phone and message, and upserts into a Google Sheet by email so one person stays one row. No AI.

NEEDS
Webhook · Sheets. n8n Cloud or self-hosted, n8n 1.x (import-tested on 1.123.91).

SET UP (about 10 min)
1. In n8n: Workflows > Import from file > pick lead-capture-sample.json.
2. Read the yellow note on the canvas, then fill the Config node if there is one.
3. Open each node with a red warning and pick your own credential. Nothing is hard-coded.
4. Test with your own email or a test form post first. Then activate.
